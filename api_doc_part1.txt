DOKUMENTASI API
Versi 1.1.0 ΓÇö Dokumentasi Implementasi Terbaru
Dokumentasi kondisi API Tetasco Connect setelah integrasi FastAPI, PostgreSQL, kontrol perangkat Raspberry Pi GPIO, dan penyimpanan histori sensor berbasis timestamp.
1. Arsitektur Sistem
Raspberry Pi menjalankan Docker Compose. Nginx melayani frontend dan reverse proxy FastAPI, PostgreSQL menyimpan data, dan Hardware API menangani GPIO.
Internet/Client ΓåÆ Nginx :80
Nginx ΓåÆ frontend static files
Nginx /api/ ΓåÆ FastAPI :8000
FastAPI ΓåÆ PostgreSQL melalui database:5432
FastAPI ΓåÆ Hardware API melalui host.docker.internal:5001
Hardware API ΓåÆ GPIO Raspberry Pi

8. Konsep Penyimpanan Sensor
Setiap pembacaan yang dikirim disimpan sebagai satu record. Tidak ada pembatasan satu record per jam dan tidak ada scheduler/cron. Timestamp dicatat oleh PostgreSQL saat record dibuat.
Endpoint history/hourly pernah diuji untuk agregasi, tetapi bukan bagian dari mekanisme penyimpanan utama.

Service utama: backend, database, dan nginx. PostgreSQL menggunakan named volume postgres_data. Backend menggunakan DATABASE_URL menuju service database pada port 5432.

17. Keamanan & Catatan
Port hardware API 5001 sebaiknya hanya internal.
Password PostgreSQL tidak boleh dimasukkan ke dokumentasi publik.
Endpoint kontrol perangkat belum menggunakan autentikasi/otorisasi.
Heater 2 dan UV belum memiliki mapping GPIO.
Penyimpanan sensor tidak menggunakan scheduler; data tersimpan ketika endpoint menerima pembacaan.
Timestamp berasal dari PostgreSQL CURRENT_TIMESTAMP.
